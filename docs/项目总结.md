# 项目总结 — OpenClaw Admin

> 最后更新：2026-05-07

## 一句话

OpenClaw Admin 是一个 **双网关 AI 智能体管理平台**——一套前端同时管理 **OpenClaw Gateway** 和 **Hermes Agent**，支持多租户部署。

---

## 核心架构

```
┌─────────────────────────────────────────────────────┐
│                    浏览器 (Vue 3 SPA)                 │
│  Vue Router → Pinia Stores → Naive UI Components     │
│  WebSocket (OpenClaw)  │  HTTP/SSE (Hermes)          │
└───────────────────┬─────────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────────┐
│              Express 后端 (server/)                   │
│  ┌──────────┐ ┌──────────────┐ ┌─────────────────┐  │
│  │ gateway  │ │hermes-proxy  │ │ database.js     │  │
│  │ .js      │ │ .js          │ │ (better-sqlite3)│  │
│  └──────────┘ └──────────────┘ └─────────────────┘  │
│  ┌──────────┐ ┌──────────────┐ ┌─────────────────┐  │
│  │ index.js │ │node-pty (CLI)│ │ 客户管理 / License│  │
│  └──────────┘ └──────────────┘ └─────────────────┘  │
└───────────────────┬─────────────────────────────────┘
                    │
    ┌───────────────┼───────────────┐
    ▼               ▼               ▼
OpenClaw GW    Hermes Web UI   Hermes API Svr
:18789 (WS)    :9119 (HTTP)    :8642 (OpenAI兼容)
```

## 关键技术决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 状态管理 | Pinia | Vue 3 官方推荐 |
| UI 库 | Naive UI | TS 友好、主题变量体系完善 |
| 数据库 | SQLite (better-sqlite3) | 零运维、适合单机部署 |
| 终端 | node-pty + xterm.js | 真实 PTY，非模拟 |
| 部署 | PM2 / Docker | 生产级进程管理 |
| 认证 | Bearer Token | 简单，兼容 SPA |
| 环境加载 | `--env-file=.env` (Node 原生) | Vite 的 dotenv 不影响后端 |

## 已知坑

| 问题 | 解决方案 |
|------|----------|
| `node-pty` / `better-sqlite3` 跨平台不兼容 | **永远不在本地同步 `node_modules`**，在目标机器 `npm install` |
| Chrome 自动填充覆盖配置字段 | 所有 input 加 `autocomplete="new-password"` |
| `ecosystem.config.js` 在 ESM 项目报错 | 必须用 `.cjs` 扩展名 |
| 路由守卫 Setup 检查 | 错误时返回 `false`（默认需要设置），防止跳过 |
| 主题变量冲突 | 使用 `:deep()` 穿透 `v-html` 内容，scoped 样式限定范围 |

## 快速命令

```bash
# 开发
npm run dev:all          # 前后端一起
npm run dev              # 仅前端 (:3001)
npm run dev:server       # 仅后端 (:3000)

# 生产
npm run build            # 构建
npm run start            # 启动

# 远程部署
rsync -avz --exclude=node_modules --exclude=.env --exclude=data \
  . tomlee@192.168.31.164:~/openclaw-admin/

# PM2 管理
pm2 status               # 查看状态
pm2 logs                 # 查看日志
pm2 restart openclaw-admin  # 重启
pm2 save                 # 保存进程列表

# Docker
docker compose up -d --build
```
