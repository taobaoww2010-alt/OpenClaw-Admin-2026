## 1. 产品概览

### 1.1 什么是 Daoyi-Claw

Daoyi-Claw 是一套面向 AI 数字员工的总控管理平台，提供三个独立视角：

| 视角 | 定位 | 适用场景 |
|------|------|---------|
| **Boss 总控台** | 管理与指挥 | 查看数字员工状态、派发任务、监控告警、生成日报 |
| **协作空间** | 多智能体协作 | 创建场景、委派任务、Agent 间通信 |
| **虚拟公司** | 可视化监控 | 以可视化办公室场景查看数字员工工作状态 |

## 2. 快速上手

### 2.1 登录

1. 打开浏览器访问 `http://你的服务器IP:3001`
2. 输入用户名和密码（默认 `admin / admin`）
3. 登录成功后跳转到 Boss 指挥台

> **提示**：首次使用时需等待 OpenClaw Gateway 连接成功，页面顶部会显示连接状态指示灯。

### 2.2 连接状态指示

页面右上角显示两个网关连接状态：

- **OpenClaw**：WebSocket 连接状态（绿 = 已连接，红 = 断开）
- **Hermes**：REST API 连接状态

### 2.3 首页：数字员工指挥台

登录后默认进入 Boss 指挥台，展示：

- **系统状态卡片**：Gateway 版本、在线 Agent 数、会话数
- **Token 趋势图**：24 小时内 Token 使用情况
- **事件流**：实时 Gateway 事件
- **模型/渠道分布**：Top 统计

## 3. 数字员工 Boss

### 3.1 数字员工指挥 (`/boss/dashboard`)

**功能**：总览所有数字员工运行状态

- 查看 Agent 在线状态、任务执行情况
- 监控 Token 消耗趋势
- 实时事件流滚动显示
- 模型使用量排名

### 3.2 任务看板 (`/boss/tasks`)

**功能**：以看板形式管理所有任务

**看板列**：
| 列名 | 含义 |
|------|------|
| 待处理 | 新创建或等待执行的任务 |
| 进行中 | 正在执行的任务 |
| 审核中 | 执行完毕待确认 |
| 已完成 | 已完成的任务 |

**操作**：
- **推进**：将任务向下一阶段推进
- **智能派发**：AI 自动分配任务到合适 Agent
- **新建任务**：手动创建任务
- **搜索**：按关键词筛选任务

### 3.3 Agent管理 (`/boss/agents`)

**功能**：管理所有数字员工

**列表字段**：
| 字段 | 说明 |
|------|------|
| 名称 | Agent 名称 |
| 角色 | 职责描述（如"选品专员"） |
| 平台 | 所属平台（Hermes 主控 / OpenClaw Worker） |
| 模型 | 使用的 AI 模型 |
| 状态 | active / offline |
| 任务 | 当前任务 / 总任务数 |

### 3.4 告警中心 (`/boss/alerts`)

**功能**：集中管理和查看系统告警

- 查看所有活跃/已解决告警
- 按严重级别筛选（高/中/低）
- 告警详情查看与处理
- 支持 Telegram 推送配置

### 3.5 Agent 日报 (`/boss/reports`)

**功能**：生成和查看数字员工工作日报

- **AI 生成日报**：一键由 AI 自动生成
- **手动编辑**：自行编辑日报内容
- **历史日报**：按日期查看历史记录

## 4. 协作空间

### 4.1 智能体工坊 (`/office`)

**功能**：多智能体协作办公空间

**核心功能**：
- **场景管理**：创建和管理协作场景
- **Agent 列表**：查看当前办公楼层中的 Agent
- **会话管理**：查看和管理 Agent 的对话会话
- **团队任务**：管理多 Agent 协作任务
- **通信开关**：控制 Agent 间通信

**Agent 卡片信息**：
- 名称和角色
- 在线状态（空闲/离线/工作中）
- 会话数和 Token 用量
- 快捷操作按钮

### 4.2 虚拟公司 (`/myworld`)

**功能**：可视化办公场景

- 以楼层平面图方式展示办公区域
- 每个 Agent 以角色图标显示在工位上
- 支持缩放和平移查看
- 区域互动功能

**区域类型**：前台、办公室、会议室、茶水间、休息室等

## 5. 基础设施

### 5.1 会话管理 (`/sessions`)

**功能**：管理所有 AI 对话会话

**列表字段**：会话 Key、对话方、消息数、模型、Token 用量、最近活动时间

**操作**：
- 新建会话
- 搜索/筛选（按渠道、模型、时间排序）
- 批量选择删除
- 进入会话详情查看完整对话

### 5.2 模型管理 (`/models`)

**功能**：配置和管理 AI 模型渠道

- 渠道列表管理（支持多 Provider）
- API Key 安全管理（掩码显示）
- 模型探测功能
- 默认模型切换
- **Coding 套餐快捷配置**：一键配置 GLM/Kimi/MiniMax/阿里云

### 5.3 频道管理 (`/channels`)

**功能**：配置消息平台接入

**支持渠道**：
| 渠道 | 协议 | 说明 |
|------|------|------|
| QQ | qqbot | 群聊与私聊场景 |
| 飞书 | feishu | 企业协作场景 |
| 钉钉 | dingtalk | 机器人接入 |
| 企业微信 | wecom | 企业应用接入 |

每个渠道支持：
- 安装与配置向导
- 凭证更新（掩码保护）
- 官方教学文档链接

### 5.4 任务计划 (`/cron`)

**功能**：定时任务管理

**调度类型**：
- **Cron**：按 Cron 表达式定期执行
- **Every**：固定间隔执行
- **At**：一次性定时触发

**快捷模板**：每日晨报、健康巡检、主会话提醒

### 5.5 记忆管理 (`/memory`)

**功能**：编辑 Agent 核心文档

**可编辑文档**：
| 文档 | 文件 | 影响 |
|------|------|------|
| 主行为规则 | AGENTS.md | 高 |
| 人格风格 | SOUL.md | 高 |
| 身份信息 | IDENTITY.md | 中 |
| 用户偏好 | USER.md | 中 |
| 工具说明 | TOOLS.md | 低 |
| 心跳提示 | HEARTBEAT.md | 中 |
| 启动注入 | BOOTSTRAP.md | 高 |
| 长期记忆 | MEMORY.md | 中 |

### 5.6 技能管理 (`/skills`)

**功能**：管理已加载的技能插件

**分类**：
- **我创建的插件**（外部插件）：如 feishu-doc、browser-automation 等
- **系统内置**：40+ 内置技能（1password、github、weather 等）

每个技能支持：
- Chat 可见性开关
- 搜索过滤
- 安装/卸载

### 5.7 文件浏览器 (`/files`)

**功能**：浏览和管理 Agent 工作区文件

- 目录树浏览
- 文件查看/编辑/下载
- 新建文件/目录
- 上传文件
- 文件重命名/删除
- 支持 Markdown、代码等文件的语法高亮预览

### 5.8 远程终端 (`/terminal`)

**功能**：通过浏览器访问服务器终端

- 基于 xterm.js 的真实终端体验
- SSE 协议传输，无需 WebSocket
- 全屏模式
- 自定义 Shell 和工作目录配置
- 右键粘贴、选中复制

### 5.9 远程桌面 (`/remote-desktop`)

**功能**：远程桌面访问

- 支持 Linux/Windows 远程桌面
- SSE 实时画面传输
- 鼠标、键盘、剪贴板同步操作
- 全屏模式

> **注意**：远程桌面需要额外的依赖安装，Linux 和 Windows 各有不同要求。

## 6. 系统管理

### 6.1 系统监视器 (`/system`)

**功能**：实时监控系统资源

**监控指标**：
- **CPU**：使用率、核心数、型号

**备份内容**：
- SQLite 数据库
- OpenClaw 配置文件
- Web Admin 配置

- 工作区元数据

**操作**：
- 创建备份
- 上传备份文件
- 恢复备份

> 此页面为占位页面，后续版本将实现完整的连接管理界面。

**功能**：配置系统核心参数

## 7. 常见问题

### Q1: 登录后页面空白？

检查 OpenClaw Gateway 是否正常运行：
```bash
# 检查 Gateway 进程
ps aux | grep openclaw

# 检查端口
curl http://localhost:18789/health
```

### Q2: 连接状态显示红色？

1. 进入系统设置，检查 OpenClaw URL 是否正确（默认 `ws://localhost:18789`）
2. 检查 Token 或密码是否正确
3. 保存后会自动重连

### Q3: 远程终端连接失败？

- 确保服务器有可用 Shell（bash/zsh）
- 检查 node-pty 依赖是否正常安装
- Linux 服务器需要安装 `build-essential`

### Q4: 远程桌面无法使用？

- Linux 需要安装 `xvfb`、`x11vnc` 等依赖
- Windows 需要启用远程桌面服务
- 详细依赖见页面内"依赖要求"弹窗

### Q5: 数据备份失败？

- 确保数据库文件未被占用
- 检查磁盘空间是否充足
- 备份文件存储在 `data/` 目录下
