## 一、产品定位

### 1.1 一句话定义

**OpenClaw Admin 是一个面向 AI 智能体（Agent）的可视化管理平台**，为运维人员和管理员提供对 OpenClaw Gateway 和 Hermes Agent 两大网关的统一管控能力。

### 1.2 目标用户

| 角色 | 典型场景 | 核心诉求 |
|------|----------|----------|
| **系统管理员** | 部署、配置、监控 AI 网关 | 一站式完成所有连接配置，降低运维门槛 |
| **AI 工程师** | 调试 Agent、查看会话、管理模型 | 实时查看对话内容、Token 用量、模型切换 |
| **业务运营** | 任务派发、效果分析、报告生成 | Boss 总控台全局视图，任务跟踪和报表 |
| **企业客户** | 独立部署、独立授权 | License 授权验证、独立配置、使用期限控制 |

### 1.3 产品价值

- **降低 AI 网关使用门槛**：将命令行操作转化为可视化界面，非技术用户也能管理 Agent
- **统一管控双网关**：OpenClaw + Hermes 一套平台搞定，无需多端切换
- **企业级部署能力**：多租户 + License 授权 + Docker 部署

## 三、核心业务流程

### 3.1 首次部署 — Setup Wizard 流程

```
[访问系统]
    │
    ▼
[路由守卫检查 /api/setup/status]
    │
    ├── setupCompleted = true → 进入 Dashboard
    │
    └── setupCompleted = false → 跳转 Settings 页面
            │
            ├── Step 1: 公司基本信息 (名称、描述)
            ├── Step 2: 模型配置 (API 地址、Key)
            ├── Step 3: Hermes 配置 (Web UI + API 地址)
            ├── Step 4: OpenClaw 配置 (WS 地址 + 认证)
            └── Step 5: License 激活 (密钥验证)
                    │
                    ▼
                [保存配置 → setupCompleted = true]
                    │
                    ▼
                [进入 Dashboard]
```

### 3.2 用户认证流程

```
[访问受保护页面]
    │
    ▼
[authEnabled?]
    ├── NO → 跳过认证，直接进入
    │
    └── YES
        ├── 已登录 → 检查 Token 有效性
        │   ├── 有效 → 放行
        │   └── 无效 → 跳转 Login
        │
        └── 未登录 → 跳转 Login (保留 redirect 参数)
```

### 3.3 多租户授权流程

```
[管理员在总后台创建客户]
    │
    ├── 填写客户信息 (公司名、联系人)
    ├── 设置授权期限 (天数)
    ├── 生成独立 License Key
    └── 保存
        │
        ▼
[客户部署系统]
    │
    ├── 输入 License Key
    ├── 验证 Key 有效性
    ├── 激活系统
    └── 加载独立配置
        │
        ▼
[授权到期前]
    ├── 系统提醒续期
    └── 到期后系统锁定
```

### 3.4 会话生命周期

```
[用户发起对话]
    │
    ▼
[OpenClaw/Hermes 创建 Session]
    │
    ├── 实时交互 (WebSocket / SSE)
    ├── Token 用量统计
    ├── 消息历史存储
    └── 支持重置/删除
        │
        ▼
[会话结束 → 数据归档]
```

## 四、功能需求详述

### 4.1 Boss 总控台

#### 4.1.1 仪表盘

| 字段 | 说明 |
|------|------|
| 总智能体数 | 当前平台注册 Agent 总量 |
| 活跃会话数 | 正在进行的对话数量 |
| 今日 Token 消耗 | 当日累计 Token 使用量 |
| 告警数量 | 未处理的告警条目 |
| Token 趋势图 | 近 7 天 Token 用量折线 |
| 模型分布 | 各模型使用占比饼图 |
| 事件流 | 实时事件列表（新会话、任务完成等） |

#### 4.1.2 任务看板

- 支持创建任务并分配给指定 Agent
- 任务状态流转：待执行 → 执行中 → 已完成 / 失败
- 支持按状态筛选、按时间排序

#### 4.1.3 告警中心

- 自动捕获：网关断连、Agent 异常、License 即将到期
- 手动创建：管理员手动录入异常
- 状态管理：未处理 → 已处理

#### 4.1.4 报表系统

- 按日期生成统计报告
- 包含：Token 用量、会话数量、活跃 Agent 排行
- 支持删除历史报表

### 4.2 协作空间

#### 4.2.1 智能体工坊 (Office)

- 多智能体协作空间
- 支持场景创建向导
- Agent 间任务委派与消息传递
- 团队管理（添加/移除成员）

#### 4.2.2 虚拟公司 (MyWorld)

- 可视化办公场景（2D 地图）
- Agent 角色在场景中移动
- 区域互动（会议室、工位等）
- 实时状态同步

### 4.3 核心功能模块

#### 4.3.1 会话管理

| 功能 | 说明 |
|------|------|
| 会话列表 | 分页展示，支持搜索 |
| 全文搜索 | FTS5 全文检索（Hermes） |
| 消息查看 | 单条会话的完整对话历史 |
| 重置/删除 | 清空上下文或彻底删除 |

#### 4.3.2 模型管理

| 功能 | 说明 |
|------|------|
| 多模型渠道 | 支持 OpenAI、Anthropic、本地模型等 |
| API Key 管理 | 脱敏显示，仅提交新值 |
| 模型探测 | 测试模型是否可用 |
| Coding 套餐 | 快捷配置推荐模型组合 |
| 默认模型设置 | 全局默认使用模型 |

#### 4.3.3 频道管理

支持以下渠道接入：
- **IM 渠道**：QQ、飞书、钉钉、企业微信
- **社交渠道**：Telegram、Discord、Slack
- 渠道状态实时监控
- 一键安装与配置向导
- OAuth 认证管理

#### 4.3.4 任务计划

- Cron 表达式 / 固定间隔 / 指定时间
- 快捷模板：晨报、健康巡检等
- 任务执行历史
- 暂停/恢复/手动触发

#### 4.3.5 记忆管理

- 编辑 Agent 核心文档：`SOUL.md`、`AGENTS.md`、`IDENTITY`、`USER`
- Markdown 编辑器
- 模板片段快速插入

#### 4.3.6 技能管理

- 内置技能 / 用户安装技能分类
- 启用/禁用切换
- 版本信息与描述
- Chat 可见性控制

#### 4.3.7 远程终端

- 基于 node-pty 的真实终端体验
- SSE 流式传输
- 会话持久化（断开不中断进程）
- 全屏模式、右键粘贴、选中复制
- 支持多节点切换

#### 4.3.8 远程桌面

- Linux / Windows 远程桌面
- WebRTC 实时画面传输
- 鼠标键盘操作
- 剪贴板同步

#### 4.3.9 文件浏览

- 工作区文件树
- 文件编辑与预览
- 上传/下载/删除
- 目录创建与导航

### 4.4 系统管理

#### 4.4.1 客户管理（多租户）

#### 4.4.3 数据备份

- 备份列表与恢复
- 备份文件大小与时间

- 显示 OpenClaw / Hermes 连接状态
- 连接/断开操作

## 五、非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面首屏加载 | < 3s（生产环境） |
| API 响应时间 | < 500ms（本地网关） |
| 终端延迟 | < 100ms（键盘到回显） |
| 并发会话 | 支持 50+ 并发会话 |
| 内存占用 | 服务端 < 500MB |

### 5.2 安全性

- 认证信息（Token、API Key）不持久化到前端
- 凭证字段掩码显示，不回显明文
- 仅支持本地地址（127.0.0.1 / localhost）连接网关
- License Key 防伪造验证机制
- HTTPS 部署支持

### 5.3 兼容性

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 90+ / Safari 14+ / Edge 90+ |
| Node.js | >= 18.0.0 |
| OpenClaw Gateway | 2026.4.5 及以上 |
| Hermes Agent | 2026.4.9 及以上 |
| 操作系统 | Ubuntu 22.04+ / macOS / Windows（仅开发） |

### 5.4 可靠性

- PM2 守护进程，崩溃自动重启
- Docker 容器健康检查
- SQLite WAL 模式防数据损坏
- CLI 会话孤儿超时回收（2 小时）

### 5.5 可维护性

- 前后端分离架构（Vite + Express）
- TypeScript 类型安全
- 统一代码规范（2 空格缩进、单引号、尾逗号）
- Docker 一键部署

## 六、技术约束

### 6.1 必须遵守

1. **网关必须本地部署**：`.env` 中网关地址仅限 `127.0.0.1` 或 `localhost`
2. **禁止提交敏感信息**：真实 Token、API Key 等不得进入代码库
3. **跨平台编译**：`node-pty` 和 `better-sqlite3` 必须在目标机器编译
4. **ESM 模块规范**：项目使用 `"type": "module"`，配置文件需 `.cjs` 扩展名

### 6.2 技术栈锁定

| 层级 | 技术 | 原因 |
|------|------|------|
| 前端 | Vue 3 + TypeScript + Vite | 团队技术栈统一 |
| UI | Naive UI | TS 原生支持、主题体系完善 |
| 状态 | Pinia | Vue 3 官方推荐 |
| 后端 | Express 5 | 轻量、易扩展 |
| 数据库 | SQLite (better-sqlite3) | 零运维、单机部署足够 |
| 终端 | node-pty + xterm.js | 真实 PTY 支持 |
| 部署 | Docker / PM2 | 生产级标准方案 |

## 十、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 网关协议变更 | 功能失效 | 与 OpenClaw 团队保持同步，版本兼容性表 |
| License 被破解 | 商业损失 | 未来接入远程验证服务，加密签名 |
| 跨平台部署失败 | 客户无法使用 | Docker 标准化部署，屏蔽 OS 差异 |
| 数据丢失 | 业务中断 | 定期备份机制，SQLite WAL 模式 |
| 前端构建体积大 | 加载慢 | 路由懒加载、代码分割、CDN |
